# KAABIL (काबिल) — Kanban Recruitment Pipeline Guide

---

## 1. Visual Pipeline Overview

The Recruitment Pipeline (`/employer/pipeline`) provides a drag-free, accessible Kanban board for recruiters and hiring managers. It groups active applications across 6 primary workflow columns:

1. **Applied** (New Incoming Candidates)
2. **Under Review** (Active Portfolio / Passport Inspection)
3. **Shortlisted** (Qualified Benchmarks)
4. **Interview** (Technical & Behavioral Assessments)
5. **Offer Extended** (Compensation & Letter Extended)
6. **Hired** (Accepted & Finalized)

---

## 2. Accessible Stage Transitions

In compliance with WCAG 2.1 AA accessibility guidelines, stage progression does not rely exclusively on pointer-drag interactions. Every candidate card features explicit **Advance**, **Back**, and **Reject** action buttons, with timestamped audit logging of all stage movements.
