# KAABIL (काबिल) — Applicant Tracking System (ATS) Guide

---

## 1. Candidate Application Architecture

When an adult student applies for an opportunity, the application record connects the student's verified Digital Skill Passport directly to the recruiter's evaluation pipeline.

### Application Stages:
1. **`APPLIED`:** Candidate has submitted application with voluntary DPDP data sharing consent.
2. **`UNDER_REVIEW`:** Recruiter has opened and begun reviewing verified credentials and project evidence.
3. **`SHORTLISTED`:** Candidate meets or exceeds minimum competency benchmarks.
4. **`INTERVIEW_SCHEDULED`:** Recruiter or hiring manager has booked a virtual or on-site evaluation slot.
5. **`OFFER_ISSUED`:** Formal offer extended with disclosed compensation terms.
6. **`HIRED`:** Candidate has accepted the offer and completed recruitment onboarding.
7. **`REJECTED`:** Candidate not selected (requires human review and internal evaluation notes).
8. **`WITHDRAWN`:** Candidate voluntarily rescinded application; data minimized per statutory rights.

---

## 2. Explainable Competency Matching

Unlike black-box ATS algorithms that discard candidates without clear justification, KAABIL computes a **transparent match breakdown**:
- **Stream Alignment (25%):** Confirms if candidate's academic discipline aligns with or bridges into the target opportunity.
- **Stage Alignment (25%):** Validates academic level (e.g. Undergraduate, ITI, Diploma).
- **Competency Verification (50%):** Validates required mandatory skills against verified evidence stored in the candidate's Digital Skill Passport.
- **Detailed Gap Feedback:** Clearly highlights which competencies were verified versus missing, allowing recruiters to make informed hiring or upskilling decisions.
